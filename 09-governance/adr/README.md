# ADR Log

Every decision about the guidelines is an ADR (Def. X.3) in this folder, kept under Prop. X.6. Numbers are permanent and sequential; nothing here is deleted or renumbered. A reversed decision is recorded by a new ADR that marks the old one superseded.

New ADRs are written from [`templates/adr.md`](../../templates/adr.md) and arrive by proposal (Prop. X.1). Exceptions (Prop. X.2) share this number space.
