# ADR Log

Every decision about the guidelines is an ADR ([Def. X.3](../definitions.md#Def.%20X.3%20-%20ADR)) in this folder, kept under [Prop. X.6](../propositions/06-the-adr-log.md). Numbers are permanent and sequential; nothing here is deleted or renumbered. A reversed decision is recorded by a new ADR that marks the old one superseded.

New ADRs are written from [`templates/adr.md`](../../templates/adr.md) and arrive by proposal ([Prop. X.1](../propositions/01-change-by-pull-request-with-adr.md)). Exceptions ([Prop. X.2](../propositions/02-exception-process.md)) share this number space.
